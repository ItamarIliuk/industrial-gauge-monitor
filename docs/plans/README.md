# Planos

Um arquivo por plano. Qualquer máquina (workstation ou notebook) pode criar ou atualizar,
desde que faça `git pull --rebase` antes e commit + push depois.

Modelo de cabeçalho:

```markdown
# <título do plano>
Estado: rascunho | em andamento | concluído
Máquina onde roda: workstation | notebook | qualquer
Última atualização: AAAA-MM-DD

## Objetivo
## Passos
## Pendências / dúvidas
```
